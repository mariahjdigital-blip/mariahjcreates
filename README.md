# mariahjcreates.com

Mariah J Creates: link-in-bio, portfolio, freebies, shop, blog and work-with-me pages.

## Editing (no code needed)
Go to https://app.pagescms.org, sign in with GitHub and open this site. Every section has its own form:

- **Profile & socials:** name, bio, photo, social links (leave a link blank to hide its icon)
- **Link-in-bio buttons:** add, remove, reorder or hide buttons
- **Portfolio:** services and brand work (upload a video or cover photo)
- **Freebies:** each freebie gets its own page at /freebies/your-page-address, plus a PDF to download
- **Shop:** ShopMy link and affiliate favorites with categories
- **Blog posts:** write, add a cover photo, publish or hide

Click **Save**. The live site updates in about a minute.

## Where things live
- `content/`: all text and links (what Pages CMS edits)
- `images/`: photos and uploads
- `assets/`: design (styles.css) and page logic (site.js). Ask Claude before changing these.
- Freebie signups and brand inquiries appear in Netlify under **Forms**.
